# Modelo y estructura de base de datos (Etapa 1)

Etapa 1: aún no hay entidades de negocio. H2 en archivo `data/sigrdb` se crea al arrancar
(`spring.jpa.hibernate.ddl-auto=update`). En próximas etapas se definirán usuarios, roles,
categorías, platos, mesas, pedidos, detalles, reservas, facturas, pagos y caja con diagrama,
diccionario de datos y script reproducible de esquema/datos demo.
Zona horaria: America/Bogota. Moneda: COP con BigDecimal.
